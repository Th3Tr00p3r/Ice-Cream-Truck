# Ice-Cream-Truck

### Nuitka Bundling

nuitka --onefile --include-data-dir=./assets=assets --windows-icon-from-ico=./assets/images/cat/big_tile_image1.png  ice_cream_truck.py

### Web Version

Play it in the browser at https://th3tr00p3r.github.io/Ice-Cream-Truck/ (deployed from `master` by GitHub Actions).

To run it locally: `python web/serve.py [host]`, then open `http://<host>:8000/` (default host: localhost).

On an Android tablet, open the page in Chrome and pick "⋮ menu → Add to Home screen" (or "Install app") to launch it fullscreen like an app.
